# Open Source Character Illustration and PNG Exporter

Frostmarrow Mask is an open source SVG character illustration project with a browser based transparent PNG exporter. It depicts a hooded character wearing a skeleton mask split between ice blue and maroon, with blue eyes, brown hair, black clothing, grey knee pads, and grey boots.

## Install

1. Download or clone the project files.
2. Keep `skeleton-mask-character.svg` and `export-transparent-png.html` in an accessible folder.
3. Open `export-transparent-png.html` in a modern web browser.

## Use

1. Open the exporter page.
2. Select `skeleton-mask-character.svg`.
3. Click Download transparent PNG.
4. The exporter removes the illustration background and ground shadow.
5. Save the generated 1400 × 1800 transparent PNG.

You can also open `skeleton-mask-character.svg` directly in an SVG compatible browser or graphics editor. The SVG uses a 700 × 900 viewBox and includes accessible title and description metadata.
